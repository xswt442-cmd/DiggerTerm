# User theme examples

Copy a JSON file and its same-stem CSS file into the `DiggerTerm/` directory shown in Settings → Appearance. DiggerTerm stores this directory under the current user's home directory. JSON themes require `version: 1` and a non-empty `name`; `base` may be `nightfall`, `graphite`, `pine`, or `bluehour` and defaults to `nightfall`. All color fields are optional and accept `#RGB`, `#RRGGBB`, or `#RRGGBBAA`. UI fields include `sidebar`, `canvas`, `surface`, `text`, `muted`, `accent`, and the other matching palette fields. Terminal fields include `background`, `foreground`, `cursor`, selection colors, the eight ANSI colors, and their `bright*` variants. `appearance.radius` accepts 0–24 and `appearance.paneGap` accepts 0–32.

CSS can set the stable `--dt-*` variables on `.layout[data-dt-theme]`, including `--dt-terminal-bg`, `--dt-terminal-fg`, and `--dt-terminal-cursor`. The loader parses CSS and rejects at-rules, URL tokens, CSS escapes, and functions that can load images or other resources. `custom.css` is a global override and does not add a selectable theme.
